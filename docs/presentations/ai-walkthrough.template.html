Presentation controls

Choose a story from the overview. Use Right or Space for the next prompt and Left for the previous one. Up or Escape returns to the overview. Map hides or shows the panel on the right without changing the current slide. Down enters the selected story. Keys 1 to 4 select a story from the overview.

Audience votes are manual. Click the winning prompt to select it, then copy it into the real website. The recorded path includes a genuine website screenshot at every stop. An alternate prompt shows a clear live continuation state until you return to the recorded option.

Click an image to enlarge it. Website captures are embedded, so this file works offline. Copying prompts and opening the live website require the corresponding browser features or an internet connection.

A new story starts a separate conversation. Use New chat in the website before its opening prompt.
